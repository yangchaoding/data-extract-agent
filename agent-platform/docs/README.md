## 从哪开始

第一次用，按这个顺序：

1. 看 [../README.md](../README.md) 的"构建"一节，把项目构建出来。
2. 照着 [01-read-paddleocr-vl.md](01-read-paddleocr-vl.md) 用自带的示例数据走一遍。
3. 换成你自己的识别结果再走一遍。

## 写教程的规矩

- 每个功能做完时，教程和代码在同一次提交里。
- 每一步都要实际执行过，输出照实贴，不凭印象写。
- 功能改了，教程跟着改。
- 示例数据用虚构的，不放真实的人事、财务材料。
